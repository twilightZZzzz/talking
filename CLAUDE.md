# Утренняя речь — тренажёр речи с разбором от ИИ

Владелец: Сергей. Общение на русском, коротко и по делу. Интерфейс полностью на русском.

## Что это
Ежедневный 15-минутный ритуал тренировки речи (утро) и 7-минутный экспресс (день).
Главная проблема пользователя: «каша в голове» — мысль скачет, слова-паразиты («э», «ну», «типа», «короче», «вот»).
Цель тренажёра: говорить мысль по каркасу и ставить паузу вместо «э».

Рабочий прототип: `legacy/index.html` — один HTML-файл, вся логика, тексты, геймификация, дизайн.
Он — источник правды по контенту, UX и визуалу. Переносим его, а не придумываем заново.

## Что строим (v2)
1. **Аккаунт и общий прогресс.** Вход по email (magic link) через Supabase Auth. Прогресс в Postgres, виден с телефона и ноутбука.
2. **Разбор речи по видео.** Пользователь записывает дубль на телефон, загружает файл на странице и через ~20 сек получает разбор.
3. **Деплой на Vercel**, бесплатные тарифы Vercel и Supabase. PWA: manifest + иконка из `legacy/`.

## Стек
- Next.js (App Router) + TypeScript, без UI-китов. Стили перенести из legacy (CSS-переменные, светлая и тёмная тема, шрифты Unbounded / Onest / JetBrains Mono).
- Supabase: Auth + Postgres с RLS (каждый видит только свои строки).
- OpenAI API: транскрипция. Anthropic API: разбор.
- Ключи только на сервере, в `.env.local` и в Vercel env:
  `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`.

## Поток разбора — важные решения
1. **Звук извлекается в браузере, видео на сервер не уходит.** Тело запроса к функции Vercel ограничено ~4.5 МБ, а минута видео с телефона весит 30–150 МБ.
   Шаги: `file.arrayBuffer()` → `AudioContext.decodeAudioData` → `OfflineAudioContext` (16 кГц, моно) → WAV.
   90 сек ≈ 2.9 МБ, влезает. Лимит дубля 2:30. Если `decodeAudioData` упал (бывает с .mov в Firefox), показать понятную ошибку: «Открой страницу в Safari или Chrome».
2. `POST /api/analyze` (multipart: wav + topic, frame, challenge, take_no, session_id).
3. **Транскрипция:** OpenAI `whisper-1`, `language: "ru"`, `response_format: "verbose_json"`, `timestamp_granularities: ["word","segment"]`.
   ⚠️ Whisper по умолчанию «чистит» речь и выкидывает «э-э». Обязательно передавать `prompt` с паразитами, например:
   `"Э-э, ну, значит, типа... Короче, вот. Ммм, э, как бы."` — тогда он их сохраняет. Проверь на реальной записи.
4. **Метрики считать кодом, а не моделью:**
   - паразиты: словарь (э, ээ, эм, ммм, ну, типа, короче, вот, как бы, значит, так сказать, в общем) по словам с таймкодами;
   - темп: слов в минуту (норма 120–150);
   - паузы: разрывы между словами > 0.7 сек — это хорошо, их считаем отдельно и хвалим;
   - длительность дубля.
5. **Разбор:** Anthropic Messages API, модель `claude-sonnet-5-5`, промпт из `prompts/feedback.md`. На вход транскрипт с таймкодами, метрики, тема, каркас, челлендж, итоги прошлого дубля сегодня (если был). На выход строгий JSON по схеме из промпта. Ответ валидировать (zod), при невалидном один повтор.
6. Сохранить дубль и разбор в БД, автоматически заполнить «паразиты» и «ясность» в шаге «Разбор записи». Пользователь может поправить.

## UI разбора
Карточка под шагом 03:
- 4 плитки: паразиты (число и сравнение с прошлым), темп, паузы, ясность 1–5;
- каркас: по каждому пункту ✓/✗ и короткая цитата, где он прозвучал;
- паразиты списком с таймкодами (кликабельно, если видео ещё в памяти страницы, — перемотка в `<video>`);
- «Главное, что мешает» — 1 пункт;
- «Задание на следующий дубль» — 1 конкретное действие;
- челлендж выполнен / нет, с объяснением.
Тон разбора: прямой, без воды и без сюсюканья, как тренер.

## Данные (Supabase)
- `sessions`: id, user_id, date (локальная дата пользователя, Asia/Yekaterinburg по умолчанию), mode, steps_done int[], fillers, clarity, challenge_done, breath, note, full, saved_at.
- `takes`: id, session_id, user_id, take_no, duration_s, transcript, words jsonb, metrics jsonb, feedback jsonb, created_at.
- `achievements`: user_id, code, unlocked_at.
- RLS на всех таблицах: `user_id = auth.uid()`.
- Миграции SQL в `supabase/migrations/`.

## Геймификация
Перенести из legacy без изменений логики: XP считается из истории (функция `calc()`), 8 уровней, уровни открывают сложность (подготовка 30→20→10 сек, без бумажки, тема-сюрприз), серия с множителем до ×1.5, цель недели 5/7, челлендж дня, 12 достижений, календарь на 8 недель, график паразитов за 14 дней.
Добавить:
- +15 XP за разбор дубля, +10 за второй дубль, если паразитов стало меньше, чем в первом;
- достижение «Под микроскопом» — 10 разобранных дублей;
- достижение «Метроном» — темп 120–150 три дня подряд.

4. Деплой на Vercel, проверка с телефона.
