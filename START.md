# Как продолжить в Claude Code

1. Распакуй архив, например в `~/Projects/rech-app`.
2. Открой терминал в этой папке и запусти `claude`.
3. Вставь первое сообщение:

> Прочитай CLAUDE.md, prompts/feedback.md и legacy/index.html. Это тренажёр речи, который мы переносим в полноценное приложение. Начни с этапа 1 из «Порядка работы»: каркас Next.js и перенос legacy-страницы 1:1, без бэкенда. Перед стартом задай вопросы, если что-то неясно.

## Что подготовить заранее (понадобится на этапах 2–4)
- Аккаунт на supabase.com → New project. Из Settings → API скопировать URL и anon key.
- Ключ OpenAI API (platform.openai.com) — для распознавания речи.
- Ключ Anthropic API (console.anthropic.com) — для разбора.
- Аккаунт на vercel.com (вход через GitHub).

Ключи вставлять только в `.env.local` и в настройки Vercel, не в чат и не в код.
